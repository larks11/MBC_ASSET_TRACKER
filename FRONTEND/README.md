# IAMS Frontend (React + Vite + Tailwind, JavaScript)

1. Siguroha nga nagdagan ang backend (`npm run dev` sa backend folder, port 5000).
2. Sa kani nga folder:

   npm install
   npm run dev

3. Ablihi http://localhost:5173

Ang `/api` requests gi-forward sa backend sa vite.config.js (proxy), mao nga walay CORS setup nga kinahanglan.
